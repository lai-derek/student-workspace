# Whole-workspace application audit

Use only for a requested broad audit or an observed failure affecting more than one artifact.

Sample recent or important chains from preserved original through transcription, personal record, evidence packet, draft, and evidence note. Inspect wording fidelity, identity reconciliation, fact scope, status, current-versus-imported versions, catalog coverage, source registration, and citation targets.

Check whether retrieval finds distinct useful experiences without scanning everything. Look for unsupported proficiency, causal overstatement, converted metrics, and generated language being reused as evidence. A theme is interpretation; a self-report is not independent corroboration.

Assess the exact target's criteria and constraints rather than treating structural validation as persuasive quality. Inspect saved counts and rendered output when applicable. Preserve uncertainty around official opportunity facts and applicant eligibility.

Report findings with file or source evidence and separate current defects from pre-existing imported ones. Make only authorized changes. Produce a durable report only when requested or needed to explain a material system-wide change.
