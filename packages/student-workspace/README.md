# Student Workspace (core package)

The core of [Student Workspace](https://github.com/lai-derek/student-workspace): workspace
setup and state, the source registry, backups and restore, a workspace-wide `check`,
tool registration, application handoffs and the shared application-writing skills.
Setup installs it into `tools/student-workspace/`; see the repository README for
installing and using the workspace.

More: [backup and recovery](docs/recovery.md), [application drafts](docs/applications.md),
[troubleshooting](docs/troubleshooting.md), [validation](VALIDATION.md).
