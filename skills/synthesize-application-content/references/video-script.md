# Video scripts

Establish runtime and platform. Estimate runtime from spoken word count and state the speaking-rate assumption. Use Visual and Audio columns only when visuals materially affect execution.

For an introduction video accompanying written answers, identify what the packet has not yet shown. A current interest or project may add more than another leadership recap. Reuse an experience when it reveals a new aspect; do not force every hobby into the same lesson. Use a speaking outline instead of a script when that better fits the request or unedited format.

Separate sourced events from proposed visuals, reenactments, and transitions. Do not invent dialogue or imply footage exists. Preserve natural spoken cadence rather than forcing an essay into a script.
